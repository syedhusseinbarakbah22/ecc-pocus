Formula reference

SV = π × (LVOT diameter / 2)² × VTI; CO = SV × HR / 1000; CI = CO / BSA; SVI = SV / BSA.

SVR = 80 × (MAP − CVP) / CO; SVRI = SVR × BSA; TPR = 80 × MAP / CO.

Ea = 0.9 × SBP / SV (mmHg/mL). VTI afterload index = 0.9 × SBP / VTI (mmHg/cm).

Afterload interpretation: Ea 1.0–2.0 mmHg/mL is an illustrative reference band only; values outside it are not diagnostic. VTI afterload index has no established reference range; no normal/abnormal flag is assigned. Both indices depend on loading conditions and measurement quality.

BSA = √(height × weight / 3600). The 0.9 × SBP approximation is not a direct end-systolic pressure measurement.

Approximate adult resting reference intervals: VTI 18–22 cm (context-dependent); SV 60–100 mL; SVI 35–65 mL/m²; CO 4–8 L/min; CI 2.5–4.0 L/min/m²; SVR 800–1200 dyn·s/cm⁵; SVRI 1600–2400 dyn·s·m²/cm⁵. Ea ~1.0–2.0 mmHg/mL is an illustrative resting adult band, NOT a validated diagnostic or treatment threshold. No validated universal normal range for VTI afterload index (mmHg/cm); use serial trends cautiously. Values outside ranges do not establish a diagnosis.
